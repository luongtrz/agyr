Key Advantages

Why Developers Choose agyr

Engineered specifically for the official Google Antigravity CLI. No shortcuts, no shady reverse proxies.

100% Local & Privacy-First

Your OAuth tokens stay strictly on your local filesystem under strict permissions (chmod 600) or native Windows Credential Manager. Zero third-party telemetry, zero external servers.

  • Tokens locked in ~/.gemini/antigravity-cli/accounts/
  • Atomic file writes & cross-platform file locking
  • Windows Credential Manager (gemini:antigravity) support

Zero-Ban Risk Architecture

Unlike reverse-proxy tools that get flagged by Google for datacenter IPs and forged TLS signatures, agyr directly invokes the official agy binary from your machine.

  • Authentic Google CLI binary & TLS/HTTP2 fingerprints
  • Clean D-Bus keyring isolation without binary modification
  • Zero proxy daemons listening on local network ports

Smart Scheduling & 429 Failover

Never waste quota again. agyr tracks Google quota windows dynamically, selecting replacement accounts based on weekly expiration and bottleneck heuristics.

  • Bottleneck-aware account sorting (min(Gemini 5h, Week))
  • Tie-breaking prioritizing accounts resetting soonest
  • Flawless --conversation context handover

Step-by-Step Setup

Get Started in 4 Easy Steps

Add multiple accounts once in your browser. agyr manages the credentials forever.

01

Sign in and save Account #1

Launch agyr to trigger Google's browser OAuth login, then save the active session into slot acc1. 

# Opens browser for account 1
agyr

# Save credentials into slot 'acc1'
agyr save acc1
02

Add Account #2 (and more)

Use agyr forget to clear local active tokens safely (without revoking stored slots), then sign in with your next Google account. 

# Safely clears active login (acc1 is safe)
agyr forget

# Sign in to account 2 in browser
agyr
agyr save acc2
03

Inspect Live Quota Status

Query all your accounts in parallel. View 5-hour and weekly percentages with color-coded health indicators. 

# Real-time multi-account dashboard
agyr list

# Or check fast cached values
agyr list -c
04

Run Automated Tasks with 429 Failover

Use agy-run for automated coding tasks. If an account runs dry, it switches slots and keeps coding. 

# Automated execution with 429 failover
agy-run --add-dir . \
  --prompt "Refactor database queries and add indexes"

Account Management

Cross-Platform Architecture

Native Support on Linux & Windows

Tailored platform layers ensure zero hacks and rock-solid credential isolation.

Linux Backend (file)

  • D-Bus Session Bus Bypass: Disables GNOME Keyring fallback with DBUS_SESSION_BUS_ADDRESS=unix:path=/nonexistent so agy reads swapped tokens cleanly.
  • Parallel Quota Measurement: Spawns parallel probe environments in temporary home dirs via setsid without modifying live session tokens.
  • Process Group Termination: Cleanly kills orphaned sub-agent processes and task groups without zombie leaves.

Windows Backend (wincred)

  • Windows Credential Manager: Directly swaps credentials in gemini:antigravity using native PowerShell API wrappers.
  • All Shells Supported: Generates both Git Bash scripts and native Windows .cmd wrappers for PowerShell and Command Prompt (CMD).
  • Argument Conversion Guard: Bypasses MSYS path rewrites via MSYS2_ARG_CONV_EXCL and terminates Windows process trees via taskkill //T //F.
Frequently Asked Questions

Common Questions & Answers

Can Google ban my accounts for using agyr?

No. Unlike proxy routers (which route traffic through custom servers with forged headers and cloud IPs), agyr is simply a local authentication swapper. It runs Google's official agy binary directly on your machine. To Google's servers, it looks completely identical to you logging in and out of different accounts manually.

How does agy-run maintain conversation context after hitting a 429?

When a 429 quota exhaustion is detected, agy-run terminates the current session immediately, puts that slot on cooldown, switches the active token file to the best available account, and immediately launches agy --conversation <existing-conversation-id>. Because Antigravity's conversation history is stored on disk or server session, the new account picks up the exact same context without wasting tokens re-reading files.

What happens if all my saved accounts run out of quota simultaneously?

If the entire account pool is on cooldown, agyr and agy-run cleanly exit with code 5 (or code 3 for interactive rotate) and display the exact earliest reset time in your local timezone (e.g. "all accounts on cooldown, earliest reset in 48m at 05:15 PM"). It never loops aimlessly or burns tokens.

Does agyr work with Claude Code or Gemini CLI agents?

Yes! That is one of its primary design goals. The repository ships with skills/agy/ which lets Claude Code, Antigravity, and Gemini act as orchestrator/reviewers while delegating heavy repetitive coding tasks to agy-task in isolated git worktrees.
